# Задачи WishBox RadicalMart VK

Task-плагин `plg_task_wishboxrmvk` добавляет в планировщик Joomla две задачи для обмена данными между RadicalMart и VK Маркетом.

## Настройки плагина

Перед созданием задач включите плагин группы `task` и заполните его параметры.

| Параметр | Назначение |
| --- | --- |
| ID группы VK | Идентификатор сообщества, которому принадлежит магазин VK. |
| Токен доступа VK | Токен с правами на работу с товарами и заказами сообщества. |
| Коэффициент цены товара по умолчанию | Множитель цены RadicalMart перед отправкой в VK. Используется, если у товара не заполнено дополнительное поле `price_ratio`. |
| Валюта заказа RadicalMart | Код валюты создаваемых заказов. По умолчанию `RUB`. |
| ID способа доставки RadicalMart | Способ доставки, назначаемый импортированному заказу. Значение `0` означает, что способ явно не задан. |
| ID способа оплаты RadicalMart | Способ оплаты, назначаемый импортированному заказу. Значение `0` означает, что способ явно не задан. |
| ID пользователя заказов RadicalMart | Пользователь, которому назначаются импортированные заказы. При значении `0` RadicalMart определяет или создаёт пользователя по контактам получателя. |

## Обновление товаров RadicalMart в VK Маркете

Задача обновляет до 25 товаров за один запуск. В первую очередь выбираются товары с самым старым значением дополнительного поля `updated`.

Для участия товара в синхронизации в RadicalMart должно быть заполнено дополнительное поле:

- `market_id` — идентификатор товара в VK Маркете.

Дополнительно могут использоваться:

- `price_ratio` — индивидуальный коэффициент цены товара;
- `updated` — дата и время последней успешной синхронизации.

Во время выполнения задача:

1. Рассчитывает цену VK из актуальной цены RadicalMart и коэффициента `price_ratio`.
2. Передаёт старую цену, если базовая цена RadicalMart выше итоговой.
3. Помечает товар удалённым в VK, если он снят с публикации или отсутствует на складе.
4. После успешного обновления записывает текущее время в поле `updated`.

При ошибке VK задача завершается со статусом ошибки, а сообщение записывается в журнал планировщика.

## Импорт заказов VK Маркета в RadicalMart

Задача получает последние заказы сообщества VK и создаёт отсутствующие заказы в RadicalMart.

В параметрах самой задачи задаётся количество проверяемых заказов за один запуск: от 1 до 100, по умолчанию 10.

Товары сопоставляются по дополнительному полю RadicalMart `market_id`. Если хотя бы одна позиция заказа не сопоставлена, заказ целиком не создаётся.

После успешного импорта идентификатор заказа VK сохраняется в данных заказа RadicalMart по пути:

```text
plugins.wishboxrmvk.vk_order_id
```

Это значение используется для защиты от повторного создания заказа. В журнал планировщика записывается количество созданных, пропущенных и ошибочных заказов, а также отдельное сообщение для каждой ошибки.

## Запуск задач

Создайте обе задачи в планировщике Joomla и задайте нужное расписание. Их также можно запускать из консоли Joomla.

Посмотреть список задач и их ID:

```bash
php cli/joomla.php scheduler:list
```

Запустить конкретную задачу:

```bash
php cli/joomla.php scheduler:run --id=ID_ЗАДАЧИ
```

Запустить все задачи, срок выполнения которых наступил:

```bash
php cli/joomla.php scheduler:run --all
```
